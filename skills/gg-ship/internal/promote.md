# Promote

Make an accepted result consumable and visible on destinations already authorized by the task. Do not reopen implementation choices.

## Context

Receive only the goal, authorized destinations, accepted receipts, residual risks, and current artifact identity.

## Procedure

1. Determine which authorized surfaces are required for completion.
2. Apply `gg-write` to the final response and any required artifact index, handoff, PR description, release note, deployment receipt, or notification.
3. Preserve exact artifact references and receipt-derived totals.
4. Read back external writes when the destination permits verification.

## Transition

- Return to `WORK` when promotion exposes an incomplete artifact or missing evidence.
- Return to `CRITIQUE` when evidence or artifact identity became stale.
- Complete only when every required authorized destination is current and the `gg-ship` completion gate passes.

Do not invent an audience, publish outside the assigned scope, or turn promotion into marketing.
